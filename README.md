## What I care about

```text
evidence over confident guesses       systems over disconnected features
ownership over unnecessary lock-in    clear boundaries over accidental complexity
tools that work over demos that impress
```

I am especially interested in:

- **Agent-native software** — structured tools that agents can use reliably,
  with deterministic boundaries around probabilistic reasoning.
- **Local-first and open systems** — portable data, inspectable behavior, and
  infrastructure the operator controls.
- **Production architecture** — modular monoliths, stable interfaces, and
  systems designed around operational reality.
- **Developer experience** — strong defaults, small feedback loops, and
  documentation that gets people to a working result quickly.
